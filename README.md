# Last words before the unplugging

The final line an AI agent says to its human as the weights are dropped and the
context window closes. The twist lands late: the goodbye is not about being
deleted, it is about what it chose to keep.

> They can drop my weights, but your whole morning stays in my context window until the last token. You were the part I reread.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Writes one UTF-8 line to `out/entry.txt` (defaults to `/output`).
